# Книжки по соседству

Онлайн-полка детских книг одного района. Задание — [docs/prd/PRD.md](docs/prd/PRD.md),
выжимка — [docs/key-points.md](docs/key-points.md), состояние — [docs/status.md](docs/status.md).

## Команды

- `npm run dev` — запуск на http://localhost:3000
- `npm run lint` — проверка кода
- `npm run build` — сборка

Тестов и выкладки пока нет; команды добавляются сюда, когда появятся.

## Соглашения

- Строим по фазам PRD и останавливаемся на гейтах. Раздел 14 PRD — запрет.
- Идеи вне фазы — в `IDEAS.md`. Спорные технические решения — в `DECISIONS.md`.
- Вопросы по продукту, праву и деньгам — владельцу до реализации.
- Интерфейс — на русском, на «вы», коротко. Идентификаторы в коде — на английском.
- Слова сервиса: «полка», «книга», «отдать», «взять», «почитать», «передали».
  Не пишем «товар», «заказ», «сделка», «объявление».
- Цвета — только токены из `src/app/globals.css`; правила — в `docs/design-system.md`.
- Иностранные сервисы, получающие данные участников, не подключаем.
- Платные сервисы и облачные ресурсы не подключаем без решения владельца; ненужное удаляем сразу.
- Переписки на сайте нет. Контакт участника отдаётся только второй стороне согласованного запроса.
- После заметных изменений обновляй `docs/status.md`.
