# Обложки из каталога вместо фото

Идея владельца от 6 октября 2026: участник вводит название, выбирает книгу из подсказок,
обложка и описание подставляются сами. Полка выглядит единообразно, фотографировать не нужно.

Статус: **решено владельцем 12 октября 2026** — смешанный вариант. Участник вводит название,
сервис предлагает книгу с обложкой; если книги нет, участник фотографирует, и сервис обрезает
фото под единый формат 3:4. Вопрос о правах на обложки владелец взял на себя.

## Как сделано

- Источник — поиск сайта ЛитРес (`api.litres.ru/foundation/api/search`), без ключа и без договора.
- Весь код про источник — в `src/lib/book-lookup.ts`. Сменить источник — переписать один файл.
- Наружу уходит только текст запроса. Обложки идут через наш сервер
  (`/api/book-lookup/cover`), телефон участника к ЛитРес не обращается.
- Взрослые книги (16+) в подсказки не попадают.
- Фото обрезается по центру и сжимается до 1600 px на телефоне.

## Проверка покрытия, 12 октября 2026

16 детских названий, поиск ЛитРес:

- Нашлись (9): «Вафельное сердце», «Денискины рассказы», «Цветик-семицветик», «Как говорить,
  чтобы дети слушали», «Котёнок Шмяк», «Чевостик», «Простоквашино», стихи Барто, «Муми-тролль
  и комета» (под другим названием перевода).
- Не нашлись (7): «Крошка Енот», «Петсон и Финдус», «Груффало», «Городок» и «Зимняя книга»
  Бернер, «Азбука» Маршака, сказки Сутеева, «Мой первый виммельбух».

Вывод: тексты для чтения находятся, книжки-картинки и виммельбухи — почти нет. Их придётся
фотографировать.

## Риски

- Адрес поиска не описан в документации для партнёров. ЛитРес может закрыть его или изменить
  без предупреждения; тогда подсказки пропадут, останется фото.
- Договора с ЛитРес нет. Официальный путь — партнёрский API, см. таблицу ниже.
- Читай-город отвечает ошибкой 403 (защита от роботов), Лабиринт не успел ответить за 40 секунд —
  как источники не подошли.

## Источники

| Источник | Что даёт | Что мешает |
| --- | --- | --- |
| ЛитРес, API для партнёров | Название, авторы, аннотация, возраст, жанры, обложка. Документация открыта: docs.litres.ru/public/205502033.html | Нужен договор с ЛитРес. В каталоге электронные и аудиокниги, а не бумажные издания. Поиска по названию нет: каталог скачивается целиком, искать придётся у себя |
| Open Library | Бесплатно, без договора | Проверка на 5 детских книгах: нашлись 2 («Вафельное сердце», «Денискины рассказы»), 3 не нашлись. Сервис иностранный |
| Google Books | Бесплатно до лимита | Проверить не удалось: общий лимит запросов без ключа исчерпан. Сервис иностранный |
| Лабиринт, Читай-город, Ozon | Лучшее покрытие бумажных детских книг | Открытого API для каталога я не нашёл; отдельно это не проверялось |

## Что ещё не сделано

- Сохранение книги: появится вместе со входом и базой. Тогда же обложка из каталога будет
  копироваться в наше хранилище, а не запрашиваться каждый раз.
- Ограничение частоты запросов к подсказкам.
- Ручная подгонка рамки фото: сейчас обрезка только по центру.

## Риски самой идеи

- У одной книги много изданий с разными обложками: картинка из каталога может не совпасть
  с книгой на руках.
- Каталожная обложка не показывает состояние. Его закрывает обязательное поле «Состояние».
- Книги, которых нет в каталоге, всё равно придётся фотографировать.
