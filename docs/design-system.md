# Визуальный язык

Сервис оформлен в цветах и шрифтах ANIMI (сняты с animistories.com 5 октября 2026).
Логотип ANIMI в интерфейсе не используется — см. [DECISIONS.md](../DECISIONS.md).

Живая страница со всеми элементами: `/design`.

## Цвета

Цвета заданы токенами в `src/app/globals.css`. В компонентах — только классы токенов
(`bg-bg`, `text-ink`, `border-line`, `bg-accent`), без hex-значений.

| Токен | «Бумага» | «Ночь» | Для чего |
| --- | --- | --- | --- |
| `bg` | `#F7F1E5` | `#0B2E30` | Фон страницы |
| `surface` | `#FFFDF8` | `#0D3A3C` | Поля, карточки, меню |
| `surface-2` | `#EFE6D3` | `#124446` | Метки, наведение |
| `line` | `#E0D5BD` | `#1A4F50` | Границы |
| `ink` | `#0B2E30` | `#F4ECDC` | Основной текст |
| `ink-soft` | `#48615F` | `#A9B8A9` | Второстепенный текст |
| `accent` | `#D9B36A` | `#D9B36A` | Единственный акцент — золото ANIMI |
| `accent-ink` | `#0B2E30` | `#0B2E30` | Текст на золоте |

Золото — только заливка под тёмным текстом. Золотым текстом по светлому фону не пишем:
контраст ниже 4,5:1.

Тема включается атрибутом `data-theme="paper"` или `data-theme="night"` на любом блоке.

## Три варианта на выбор

| Вариант | Как выглядит |
| --- | --- |
| Двойной | Тёмная шапка ANIMI, светлая полка. Обложки на светлом фоне |
| Бумага | Всё светлое, бирюзовый только в тексте |
| Ночь | Всё тёмное, как сайт ANIMI |

Переключатель — полоса наверху каждой страницы. После выбора владельца остаётся один вариант,
переключатель удаляется.

## Шрифты

| Шрифт | Где | Начертания |
| --- | --- | --- |
| Cormorant Garamond | Заголовки, названия книг | 500, 600, 700 |
| Inter | Весь остальной текст | переменный |

Оба шрифта — с кириллицей, ставятся из npm-пакетов `@fontsource` и отдаются с нашего сервера.
Google Fonts не подключаем.

Основной текст — 17 px. Заголовок страницы — 28–32 px, Cormorant Garamond 600.

## Правила

- Обложки — главное на экране; фон спокойный.
- Область касания — не меньше 44 px (`min-h-11`), основные кнопки — 48 px.
- У иконок есть подписи.
- Пустой экран подсказывает следующий шаг.
- Основная ширина — 360–430 px; главное действие — внизу, под большим пальцем.
