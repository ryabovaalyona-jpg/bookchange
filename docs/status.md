# Состояние проекта

Обновлено 20 октября 2026. Действующий PRD — от 9 октября (поправлено состояние книги).

## Фаза 1 «Полка»: сделано

- База PostgreSQL + Drizzle по разделу 9 PRD; на компьютере — PGlite в `.data/`.
- Вход: Яндекс ID и VK ID (по текущей документации, ждут ключей) и тестовый провайдер для
  разработки. Сессии в cookie `HttpOnly`, `SameSite=Lax`, `Secure` на сервере.
- Экран знакомства: имя, зона, 18+, почта (если её не дал провайдер), контакт по желанию,
  два отдельных согласия с версиями документов.
- Выложить книгу: подсказка из каталога ЛитРес или фото, до трёх фото, возраст, состояние,
  пометка и срок, категория, темы, комментарий. Фото: поворот, удаление метаданных, WebP 320/800/1600.
  После сохранения — «Добавить ещё одну» с возрастом и пометкой из прошлой книги.
- Каталог: поиск с опечатками (русская морфология + `pg_trgm`), подборки, фильтры по возрасту,
  категории, теме, пометке и зоне, страницы по 40 книг.
- Книга: фото, всё описание, владелец и зона, «Поделиться», превью в чатах, «Хочу эту книгу»
  записывает интерес, «Пожаловаться».
- Полка соседа: выбор нескольких книг и «Хочу эти книги» с записью интереса. Закрыта от поисковиков.
- Моя полка по статусам: править, скрыть, вернуть, удалить; причина снятия модератором.
- Профиль: имя, зона, контакт, выход, удаление аккаунта со всеми книгами и фото.
- Админка: счётчики по дням и гейт A, книги (скрыть, снять с причиной, вернуть), жалобы,
  участники (блокировка), зоны.
- Правовые страницы — черновики с пометкой «проверить у юриста». Подвал со ссылкой на ANIMI,
  нажатия пишутся в `events`.
- Стиль «Двойной» выбран, переключатель удалён.
- Автотесты: 18 модульных и 2 сквозных (вход → знакомство → книга с фото → гость находит её
  с опечаткой; фото без метаданных; ответы гостю без почты, контакта и данных входа).
- Docker Compose (приложение, PostgreSQL, Caddy), скрипты выкладки, копий и восстановления.

## Не проверено

- Docker-образ, Caddy с HTTPS, резервные копии — нет сервера и Docker на компьютере.
- Вход через настоящие Яндекс ID и VK ID — нет ключей.
- Скорость каталога на медленном 4G и «вторая книга за 30 секунд с телефона» — после выкладки.

## Ждём от владельца
