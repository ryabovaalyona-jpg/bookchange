# Состояние проекта

Обновлено 11 октября 2026. Действующий PRD — от 9 октября.

## Сделано

- Каркас приложения: Next.js 16, TypeScript, Tailwind CSS 4.
- Визуальный язык ANIMI: токены цветов, шрифты на своём сервере, базовые компоненты.
- Макеты на демо-данных: полка (`/`), книга (`/books/1`), полка соседа с выбором нескольких книг
  (`/neighbors/marina`), экран входа с Яндекс ID и VK ID (`/login`), страница стиля (`/design`),
  заглушки «Выложить» и «Моя полка».
- Три варианта стиля с переключателем.
- Справочники из PRD: возраст, категории, темы, быстрые подборки.
- Состояние книги — обязательное, четыре ступени (решение владельца от 6 октября).

Поиск и фильтры на полке работают по демо-списку из 12 книг. Базы, входа и загрузки фото пока нет.
Кнопки «Хочу эту книгу», «Поделиться», «Пожаловаться» и кнопки входа — только внешний вид.
«Хочу эти книги» на полке соседа показывает ответ фазы 1, но интерес никуда не записывает.

## Ждём от владельца

- Решить по обложкам из каталога — см. [covers.md](covers.md).
- Новый список быстрых подборок и категорий (владелец принесёт пример).
- Выбрать вариант стиля: «Двойной», «Бумага» или «Ночь».
- Подтвердить состояние книги: PRD от 9 октября расходится с решением от 6 октября
  (см. [DECISIONS.md](../DECISIONS.md)).
- Пять пунктов из раздела 15 PRD, без которых фаза 1 не начинается: закрытая группа, список зон,
  название и домен, приложения в Яндекс ID и VK ID, юрист.
- Аккаунт и сервер Yandex Cloud — только к первой выкладке: 60 дней гранта идут с создания аккаунта.
